# 👋 Добро пожаловать в Базу знаний Mentor in Tech!

Здесь собраны все материалы, гайды и полезные ссылки для участников нашей программы. Мы постарались сделать так, чтобы вы могли легко найти нужную информацию в любой момент.

## 🧭 Выберите свой путеводитель
Наши материалы разделены по ролям. Выберите тот, который подходит вам, чтобы пройти пошаговый маршрут:

* 🎓 **[Я — менти](roles/mentee/guide.md)**
  *Для тех, кто ищет поддержку, хочет сформулировать цель и найти своего ментора.*
* 👩‍💻 **[Я — ментор](roles/mentor/guide.md)**
  *Для тех, кто готов делиться опытом, направлять и поддерживать менти.*
* 🙋‍♀️ **[Я — участник](roles/participant/guide.md)**
  *Для тех, кто участвует в общих мероприятиях и ищет базовую информацию.*

* [☕ **Random Coffee**](activities/random-coffee.md) — случайные встречи для новых знакомств.
* [🧠 **Мастермайнды**](activities/masterminds.md) — групповая поддержка и разбор кейсов.

* [👥 **Групповой менторинг**](activities/group-mentoring.md) — разбор тем в кругу единомышленниц.
* [💬 **Чат менти**](activities/mentee-chat.md) — место для общения и вопросов вне сессий.
